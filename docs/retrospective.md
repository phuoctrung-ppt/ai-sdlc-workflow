# Retrospective Log (Learning Layer)

> Metrics + root-cause after every module. Not an audit log — input for skill auto-update.
> Trigger skill-updater after every 5 completed modules (or when a clear pattern appears).

## Format (one block per module)

```markdown
### YYYY-MM-DD — {module-name}
- **Estimate vs Actual**: plan tokens / actual tokens | plan hours / actual loops
- **Fix loops**: N (Critical only)
- **Root cause** (if loops > 0): ...
- **Pattern candidate**: ...
- **Action**: update skill X / add gotcha / lock decision
```
