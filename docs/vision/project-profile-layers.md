# Project profile + layers

**Branch:** `enhance/project-profile-layers`  
**Base:** `v2`  
**Date:** 2026-08-14

## Problem

v2 claimed domain-neutral but shipped full-stack defaults:

- `/plan-feature` always asked for database migrations + tenancy sync
- GENESIS filled AGENTS §4/§9/§14 even for FE-only or BE-only apps
- `agent-matrix` listed `database-worker` on generic fix loops
- `worker-scopes` assumed monorepo `packages/**` and `**/web/**` only

Porting to a single-package frontend or API-only backend required hand-trimming commands and templates every time.

## Solution

| Piece | Role |
|-------|------|
| **AGENTS.md §0** | Single source of truth: profile + layers on/off |
| **active-layers.json** | Generated by `profile-sync.py` — active agents/skills/plan sections |
| **plan-feature / architecture-plan / architect-planner** | Conditional checklists; layer off → one-line N/A |
| **context-builder** | Intersects matrix + skills with active sets |
| **worker-scopes** | Broader portable globs (`app/**`, `src/**`, `pages/**`); layer filter at dispatch |

### Profiles

`frontend` · `backend` · `fullstack` · `library` · `cli`

### Layers

`frontend` · `backend` · `database` · `multi-tenancy` · `queue` · `auth` · `devops` · `ai-llm`

**Rule:** layer off means absent — no plan section, no worker, no skill, no AGENTS sync for that layer.

## Porting (no per-repo workflow edits)

```bash
# 1. Copy .cursor/ + AGENTS.md template
# 2. Fill AGENTS.md §0 (2 minutes)
# 3. Sync
python3 .cursor/context/profile-sync.py --from-agents
python3 .cursor/context/memory-loader.py --sync
```

Optional detect:

```bash
python3 .cursor/context/profile-sync.py --detect
# review active-layers.json, then mirror into AGENTS.md §0 and re-run --from-agents
```

Do **not** fork `plan-feature.md` or `skills-manifest.v2.json` per product.

## Backward compatibility

If `active-layers.json` is missing, context-builder behaves like v2 (no layer filter).  
Default committed `active-layers.json` is fullstack-like so existing demos keep working until §0 is filled.

## Non-goals

- Auto-rewriting AGENTS.md without user approval
- Deleting agent files from `.cursor/agents/` when layer off (dispatch filter only)
- Product-domain lock-in (AI Workspace, etc.)
