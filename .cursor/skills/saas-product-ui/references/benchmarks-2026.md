# Benchmark products (product UI, 2026)

Study **in-app** surfaces — not marketing sites. Borrow patterns, not brand assets.

| Product | Best for | Signature pattern |
|---------|----------|-------------------|
| **Linear** | Power-tool daily drivers | Calm default list; Insights one click away; keyboard-first |
| **Stripe Dashboard** | Fintech / money | North-star metric permanent home; tables as primary UI |
| **Vercel** | Devtools / ops | One question per view (“did it work?”); monochrome restraint |
| **Attio** | CRM / records | Ranked attention; AI summaries as first-class surface; same record in list/hover/⌘K/page |
| **Notion** | Modular workspaces | User-controlled views; progressive disclosure |
| **PostHog** | Dense analytics | Dense data still scannable; personality without chrome noise |
| **Mercury / Ramp** | Fintech trust | High-contrast amounts; calm status language |
| **Raycast / Sentry** | Dark-first tools | Quiet chrome, keyboard density |

## Six patterns that keep winning (2026)

1. **Calm default** — show the work list first; analytics secondary (Linear).
2. **Single-metric focus** — one north-star number owns the home (Stripe, Vercel).
3. **Progressive disclosure** — depth one click / one keystroke away, not one wall of widgets.
4. **Ranked attention** — surface what to do next; do not weight every row equally (Attio).
5. **AI as surface, not sticker** — summaries/enrichment inline in records; no purple glow chrome.
6. **Multi-representation objects** — same entity in table row, hover preview, ⌘K, full page (Attio systems thinking).

## Anti-benchmarks (avoid copying)

- Dashboard wallpaper: 12 equal KPI tiles + 4 charts on first paint
- Marketing bento / scroll theater inside authenticated shell
- “AI” aesthetics (gradient orbs) instead of AI **utility**
- Competing navigations (mega top-nav + full sidebar labels)
