# Domain pack: Fintech

**Use when:** payments, banking, lending, crypto exchange, invoicing, ledgers.

## Aesthetic
- **Trust over flash.** Cool neutrals (slate/zinc); accent often blue or restrained green — never playful neon as default.
- High contrast on amounts and balances; tabular numbers for money columns.
- Dense tables acceptable; avoid decorative illustration in core money flows.

## Dials
- VARIANCE: 3–4
- MOTION: 2–3
- DENSITY: 7–8

## Patterns
- North-star metric: balance, revenue, or volume (Stripe-style permanent home).
- Status chips: cleared / pending / failed — semantic colors only.
- Confirmation on transfers, payouts, API key reveal.
- Audit trail views: mono timestamps, immutable copy tone.

## Avoid
- Gamified gradients, stock-photo lifestyles in app chrome
- Hiding fees or primary amounts in low-contrast text
