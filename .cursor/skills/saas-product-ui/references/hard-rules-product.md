# Product UI — hard rules (always copy into design spec)

Keep this list in context even when long skill docs are truncated.

1. Track = **product**. No marketing hero/bento/scroll-hijack in app shell.
2. Dials: VARIANCE 3–5 · MOTION 2–4 · DENSITY 6–8.
3. Home = work list or single focus metric — not 8–12 equal KPIs.
4. One accent color for primary CTA only; status uses semantic chips only.
5. Sidebar 240–280px; soft active state; mobile drawer.
6. Tables: toolbar + filters + empty×2 + loading skeleton matching layout.
7. AI panels = readable content surface; no sparkle/purple chrome.
8. Tokens locked in `docs/design/tokens.md` before implement.
9. Sketch required under `docs/design/sketches/{feature}/` (or DESIGN-GATE fail).
10. WCAG AA; `prefers-reduced-motion` respected.
