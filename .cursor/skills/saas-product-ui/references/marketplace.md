# Domain pack: Marketplace

**Use when:** multi-vendor listings, two-sided platforms, job boards, asset stores.

## Aesthetic
- Discovery-friendly cards and filters; slightly higher variance than fintech but still product-dense.
- Clear seller vs buyer role chrome (context switcher if needed).
- Product imagery matters — real thumbnails, not gray boxes.

## Dials
- VARIANCE: 4–5
- MOTION: 3–4
- DENSITY: 6–7

## Patterns
- Listing grid + powerful filter drawer/sidebar.
- Order/transaction tables for operators; card grids for shoppers.
- Empty states: "No listings yet" with create/list CTA per role.
- Trust signals (rating, verification) as compact badges — not hero banners in-app.

## Avoid
- E-commerce marketing landing patterns inside seller dashboard
- Infinite carousels for core inventory management
