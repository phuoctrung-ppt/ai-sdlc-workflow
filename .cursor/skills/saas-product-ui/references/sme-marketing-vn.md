# Domain notes — SME Marketing VN (marketing track)

Use with **taste-design** for public pages of AI Business Workspace / Marketing Workspace.
Not for in-app chrome (use `knowledge-hub-saas.md`).

## Audience & tone

- SME owners, agency operators, freelancers in Vietnam
- Promise: **Update Once. Run Everything.** / một nguồn sự thật
- Language: **Vietnamese first**; English secondary for export use-cases
- Avoid US-startup hype (“10x your grind”); prefer concrete ops pain (giá lệch, sale báo giá cũ, chatbot lỗi thời)

## Landing structure (module-1 test)

1. Hero: one clear outcome + one CTA (Tạo workspace / Dùng thử)
2. Pain: 3–5 concrete failures of scattered knowledge (not abstract “AI transformation”)
3. Hub diagram: Knowledge → AI layer → channels (simple, not 3D particle soup)
4. Module strip: Marketing first; others as “sắp ra mắt” if needed
5. Proof / ICP strip: SME dịch vụ, agency, startup B2B
6. CTA close

## Visual direction

| Do | Don't |
|----|-------|
| Strong type hierarchy, intentional whitespace | Inter-only + gray cards on gray |
| One brand accent; photography or custom illustration | AI-purple / neon mesh gradients |
| Asymmetric or editorial layout | Centered hero + 3 equal feature cards |
| Real product UI crop in hero (if available) | Generic robot / brain stock |

## Dials (marketing)

VARIANCE 7–8 · MOTION 5–6 · DENSITY 3–4

## Hard anti-slop (copy into design spec)

- [ ] No default Inter/Roboto-only system look without a declared display font
- [ ] No purple-to-blue AI gradient backgrounds
- [ ] No identical 3-column icon cards as the only value section
- [ ] CTA contrast AA; primary action obvious in 2 seconds
