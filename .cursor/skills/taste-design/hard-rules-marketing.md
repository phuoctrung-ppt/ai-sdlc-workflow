# Marketing UI — hard rules (always copy into design spec)

1. Track = **marketing**. Do not reuse product density dials.
2. Dials: VARIANCE 7–9 · MOTION 5–8 · DENSITY 3–5 (tune per brief).
3. Declare design read + font pairing + accent **before** layout.
4. Ban: AI-purple gradients, glassmorphism soup, centered hero + 3 equal cards, Inter-only default.
5. One primary CTA above the fold; secondary quieter.
6. Vietnamese-first copy for VN SME products unless brief says otherwise.
7. Sketch or generated reference image required before frontend implements.
8. Asset Mapping for every shipped logo/hero/background file.
9. Motion enhances hierarchy — never blocks content; respect reduced-motion.
10. WCAG AA on text/CTA.
